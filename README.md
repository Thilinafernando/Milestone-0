# Key Objectives:
Recreating Standard C Library Functions:

Implementing functions from <string.h> such as strlen, strcpy, and memcmp.
Writing memory manipulation functions like memset, memcpy, and bzero.
Implementing functions from <ctype.h> such as isalpha, isdigit, and toupper.
Memory Management:

Learning dynamic memory allocation using malloc and free.
Handling edge cases in memory-related functions to ensure robustness.
String Manipulation:

Creating functions to handle strings, including concatenation (strcat), duplication (strdup), and searching (strchr).
Gaining a deeper understanding of pointers and arrays in C.
Code Organization & Modular Design:

Structuring the codebase into multiple files to promote modularity.
Using a Makefile to automate compilation and manage dependencies.
Norm Compliance:

Writing code that strictly adheres to the Norminette style guide.
Ensuring code readability, proper indentation, and the absence of forbidden functions.
Debugging and Testing:

Debugging code using tools like gdb or printf.
Testing edge cases for robustness and memory leaks using tools like valgrind.
Preparation for Future Projects:

Building a solid foundation for future projects by having a personal library of reusable functions.
Encouraging the habit of writing reusable and efficient code.
